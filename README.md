# Tampa Bay Wage & Employment Analytics

## Project Overview
This project explores wage and employment trends across the Tampa–St. Petersburg–Clearwater metropolitan area using Tableau. The goal is to transform regional labor market data into interactive visualizations that support data-driven insights.

## Tools & Technologies
- Tableau Desktop
- Data Visualization
- Data Analysis
- Dashboard Development

## Dashboard Features
- **Geographic Wage Analysis:** County-level wage comparisons across the Tampa Bay region.
- **Industry Wage Comparison:** Analysis of average weekly wages across industries.
- **Wage vs. Employment:** Scatter plot exploring the relationship between employment levels and wages.
- **Interactive Filters:** Dynamic year and quarter selections for exploring trends over time.

## Project Objectives
- Identify geographic differences in average weekly wages.
- Compare compensation across industries.
- Explore relationships between employment and wage levels.
- Present labor market information through an interactive business intelligence dashboard.
